# Codex 积分充值：分清 Reset 和 Credits，国内用微信支付宝把额度补到账

Codex 跑到一半弹出额度用尽，多数人的第一反应是"去充值"。这个念头本身没错，问题在于 Codex 身上挂着三套不同的东西，用户习惯性把它们统称为"积分"——5 小时窗口、每周额度、以及真正意义上的 Credits。搞错对象，钱花出去额度也不会回来。

这篇先把三种机制拆开，再讲国内用户实际怎么把积分补上，以及 BeWild（bewild.ai）这类代充平台在整个流程里到底站在哪一环。

## 你缺的是哪一种"额度"

| 计量器 | 重置节奏 | 用完之后的正常现象 |
| --- | --- | --- |
| 5 小时窗口 | 滚动 5 小时 | 提示 5 小时限制，等一会儿自动恢复 |
| 每周额度 | 滚动 7 天 | 周上限耗尽，5 小时窗口可能还有余量 |
| Credits（积分） | 不重置，直接扣余额 | 套餐额度用尽后按量扣，余额归零就停下 |

关键区别在这里：积分不是重置按钮。周额度掉到 0%，买积分不会让计数器回到 100%；积分的作用是在套餐包含的用量用完之后，让支持的功能继续跑下去，按实际消耗扣。想要"立刻恢复满格"，那是另一套东西——Reset。

Reset 目前有三种形态：官方在特定活动里统一发放的 Global Reset、赠送给符合条件用户的 Banked Reset（预存重置卡，可以留着以后手动用）、以及部分账号能看到的 Instant Reset（本质是把下一周期的额度提前用掉）。三者都作用在"周期"上，而不是"余额"上。所以如果当前还剩 60% 额度就急着买 Instant Reset，结果是 60% 变成 100%，不是 160%——官方自己的说明也建议把剩余额度消耗得差不多再考虑。

判断起来其实简单：

- 离自然重置不到一天，任务不赶 → 等
- 手上还有 Banked Reset → 先用那张卡
- 额度已见底、活还得继续干、愿意按量付费 → 这才是积分的场景

## 官方 Credits 的规则，付款前值得逐条看一遍

以下内容来自 OpenAI 帮助中心当前公开的说明，不是推测：

- **适用范围有限**：积分目前只能用于 Codex（仅限 Plus 和 Pro 用户）和 ChatGPT for Excel，官方也注明支持的功能集合会变动。
- **同一份配额共享**：Plus 和 Pro 的 Codex、ChatGPT Work、Excel 走的是同一个 agentic 用量池，积分在同一个符合条件的账号上可以跨这些功能使用。
- **购买入口**：Codex 设置 → 用量 → 积分，网页端和 Codex 应用里都能买到。达到限额时页面上也会出现添加积分的选项。
- **自动充值**：可以设定最低余额和目标余额，余额跌破下限时系统用默认付款方式自动补足，还能设每月支出上限。开启时如果余额已经低于下限，可能当场就扣一次。
- **余额可能变负**：任务开始时余额为正、任务结束前被并发消耗清零，余额会变成负数。后续充值会先抵掉负数，再计入可用额度。
- **有效期 12 个月**：过期作废，不结转。不可退款（法律另有要求除外），不可转让、不能转售或赠送。
- **和钱包是两本账**：用量积分余额与 ChatGPT 钱包余额分开计算。兑换礼品卡会增加钱包金额，但不会增加用量积分。
- **团队是另一套**：ChatGPT Business 工作区用的是工作区积分池，有独立的自动增值和席位级支出控制，官方还特别说明工作区积分不是 API 积分。

顺带提一句官方目前面向美加在读大学生的 $100 Codex 额度，折合 2,500 额度，发放后 12 个月过期，走 SheerID 验证。符合条件的话，这笔钱比任何代充都划算。

## 国内用户通常卡在哪一步

规则本身不复杂，复杂的是结账那一屏。国内银行发行的外币卡在 OpenAI 的订阅和积分购买页面上被拒是常见现象，原因往往不是余额，而是风控、发卡地区和账单地址匹配。积分购买走的是同一套支付通道，所以"套餐能订、积分买不了"的情况一样会出现。

这就是第三方平台存在的理由：不是替你训练模型，而是替你完成支付动作。

第 6 步不是多余动作。用户记录里出现过订单显示完成、账号却仍是免费版的情况，早发现早处理，比过了几天再找客服容易解决。

## 什么时候这笔钱不值得花

- **离自然重置不到 24 小时**，活又不紧急：等就是了。
- **手上有一张 Banked Reset**：先用掉它。注意它不会叠加——用完之后是"旧周期被新周期取代"，如果当前还剩 30%，那 30% 直接作废。
- **只是偶尔被限额**：先看看是不是云端并行任务在偷偷烧额度，把简单任务放本地 CLI 跑，很多时候额度就够用了。
- **月成本已经接近两个 Pro 席位**：该考虑的是长期切到按量计费的 API 路径，而不是在订阅档之间反复横跳。平台的 Codex 套餐走的是按量或订阅制，正是为这类场景准备的。可以先算一遍自己最近的用量折算成美元是多少，再决定要不要换通道。

## 风险与售后，付款前心里有个数

第三方代充不是零风险操作，公开记录里有几个具体案例值得参考。

2026 年 8 月，有用户反馈 BeWild 上一笔三个月套餐到了续费节点没有自动续费成功，另一笔新购的两个月套餐订单显示完成但账号仍停留在免费版，起初客服没有及时回复；后续客服恢复沟通，两笔异常订单分别以退款和退款方案处理。同期另一个案例里，OpenAI 侧明确报出支付失败，原发票未支付，平台在核对后给出部分退款 ¥150.69，用户重新下单后订阅恢复正常。等到 8 月 25 日第三次续费时，用户再次遇到支付失败、重新购买、原发票作废、新发票生成的完整流程。

这些不是要证明平台不行，而是说明两件实际的事：

- **别在赶 deadline 的当天充值**。留出缓冲期，异常处理需要时间，客服响应速度不是你能控制的变量。
- **Session 凭据权限不小**。公开信息显示平台获取 Session 是为了自动登录对应账号并处理剩余月份的续订，"不需要密码"不等于没有授权风险。密码、邮箱验证码、MFA 恢复码、Session 和 API Key 都不该出现在任何公开评论区或截图里。

另外，积分本身在官方侧是不可退的，有效期内不用就作废。所以按需买，别一次囤太多。

## 几个常见问题

**免费档和 Go 档能买积分吗？**
按官方目前的说明，Credits 只对 Plus 和 Pro 开放，Free 和 Go 用不了这个入口。

**积分能给别人用吗？**
不能。官方明确写了不可转让、不能转售或赠送，也没有现金价值。

**积分能把每周上限撑大吗？**
不能。积分是在套餐额度耗尽后继续按量计费，它不改动周期计数器，和 Reset 是两回事。

**不同来源的价格对不上，信哪个？**
信结算页。$22.99、$24.99、$25.99 这几个数字分别来自不同时间的整理页面和用户记录，本身没有被交叉确认，付款前页面上显示多少就是多少。
